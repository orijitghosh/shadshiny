## Attribution

[shadcn/ui](https://ui.shadcn.com) and [Radix Primitives](https://www.radix-ui.com),
both MIT-licensed. No source code from those projects is copied; the CSS and
JavaScript in this package are hand-authored. Token names and `data-*` state
