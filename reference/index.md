# Package index

## Page & theming

Page wrapper, theme presets, and runtime theme control.

- [`page_shad()`](https://orijitghosh.github.io/shadshiny/reference/page_shad.md)
  : A shadshiny page
- [`shad_theme_preset()`](https://orijitghosh.github.io/shadshiny/reference/shad_theme_preset.md)
  : Wrap UI in a theme-preset scope
- [`update_shad_theme()`](https://orijitghosh.github.io/shadshiny/reference/update_shad_theme.md)
  : Switch the theme preset and/or dark mode at runtime
- [`shad_run_example()`](https://orijitghosh.github.io/shadshiny/reference/shad_run_example.md)
  : Run a bundled shadshiny example app
