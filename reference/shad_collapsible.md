# Collapsible

A single show/hide region toggled by a trigger. `input$<inputId>` is the
open state (logical).

## Usage

``` r
shad_collapsible(inputId, trigger, ..., open = FALSE, class = NULL)
```

## Arguments

- inputId:

  Input id.

- trigger:

  The tag that toggles the region.

- ...:

  Collapsible content.

- open:

  Initial open state.

- class:

  Extra CSS classes.

## Value

A collapsible tag.

## Examples

``` r
shad_collapsible("c", trigger = shad_button("Toggle"), "Hidden content",
                 open = TRUE)
#> <div data-shad="collapsible" id="c" data-open>
#>   <button class="shad-btn shad-btn--default shad-collapsible__trigger" type="button">Toggle</button>
#>   <div class="shad-collapsible__content">Hidden content</div>
#> </div>
```
