# Context menu

A right-click menu over a target area. `input$<inputId>` is the value of
the last activated item.

## Usage

``` r
shad_context_menu(inputId, target, ..., class = NULL)
```

## Arguments

- inputId:

  Input id.

- target:

  The right-clickable content.

- ...:

  Menu parts.

- class:

  Extra CSS classes.

## Value

A context-menu tag.

## Examples

``` r
shad_context_menu("cm", target = htmltools::div("Right click here"),
  shad_menu_item("back", "Back"), shad_menu_item("reload", "Reload"))
#> <div data-shad="context-menu" id="cm">
#>   <div class="shad-context-menu__zone">
#>     <div>Right click here</div>
#>   </div>
#>   <div class="shad-menu__content shad-anim-pop" hidden>
#>     <button type="button" class="shad-menu__item" data-value="back">Back</button>
#>     <button type="button" class="shad-menu__item" data-value="reload">Reload</button>
#>   </div>
#> </div>
```
