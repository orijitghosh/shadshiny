# Separator

A horizontal or vertical divider.

## Usage

``` r
shad_separator(
  orientation = c("horizontal", "vertical"),
  decorative = TRUE,
  class = NULL,
  ...
)
```

## Arguments

- orientation:

  `"horizontal"` or `"vertical"`.

- decorative:

  If `TRUE` (default), the separator is purely visual (`aria-hidden`);
  if `FALSE`, it exposes separator semantics.

- class:

  Extra CSS classes.

- ...:

  Extra attributes.

## Value

A `<div class="shad-separator">`.
