# A spinner glyph for a message footer (in-progress state)

A spinner glyph for a message footer (in-progress state)

## Usage

``` r
shad_message_spinner()
```

## Value

A spinner span for use in
[`shad_message()`](https://orijitghosh.github.io/shadshiny/reference/shad_message.md)'s
`footer`.
