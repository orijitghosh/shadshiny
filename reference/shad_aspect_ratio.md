# Aspect ratio

Constrains children to a fixed width/height ratio.

## Usage

``` r
shad_aspect_ratio(..., ratio = 16/9, class = NULL)
```

## Arguments

- ...:

  Child content (typically an `<img>`), and optional attributes.

- ratio:

  Numeric aspect ratio (width / height). Default `16/9`.

- class:

  Extra CSS classes.

## Value

A `<div class="shad-aspect-ratio">`.
