# Update a rating from the server

Update a rating from the server

## Usage

``` r
update_shad_rating(
  id,
  value = NULL,
  readonly = NULL,
  session = shiny::getDefaultReactiveDomain()
)
```

## Arguments

- id:

  Input id (namespaced automatically).

- value:

  Optional new rating.

- readonly:

  Optional logical toggling display-only mode.

- session:

  The Shiny session.

## Value

Invisibly `NULL`.
