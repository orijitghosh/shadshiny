# Pagination

A windowed pager. The item list (first / last / current ±1 / ellipses)
is rendered client-side from the seed attributes. `input$<inputId>` is
the current page number.

## Usage

``` r
shad_pagination(inputId, pages, selected = 1, class = NULL, ...)
```

## Arguments

- inputId:

  Input id.

- pages:

  Total number of pages.

- selected:

  Initial current page (1-based).

- class:

  Extra CSS classes.

- ...:

  Extra attributes on the `<nav>`.

## Value

A pagination tag.
