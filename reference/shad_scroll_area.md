# Scroll area

A container with styled overlay scrollbars. Not a Shiny input.

## Usage

``` r
shad_scroll_area(
  ...,
  height = NULL,
  orientation = c("vertical", "horizontal", "both"),
  class = NULL
)
```

## Arguments

- ...:

  Scrollable content.

- height:

  Optional CSS height for the area.

- orientation:

  `"vertical"` (default), `"horizontal"`, or `"both"`.

- class:

  Extra CSS classes.

## Value

A scroll-area tag.
