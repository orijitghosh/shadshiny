# Shimmer text

Render readable text with an optional loading shimmer.

## Usage

``` r
shad_shimmer(..., active = TRUE, class = NULL)
```

## Arguments

- ...:

  Text content and optional attributes.

- active:

  One scalar logical indicating whether the shimmer is active.

- class:

  Extra CSS classes.

## Value

A span tag.
