# carousel (Tier 3)

Scroll-snap based – dragging/swiping is native scrolling; JS adds paging buttons, dots, index tracking.

## Anatomy
```
div.shad-carousel[data-shad=carousel]
├─ div.shad-carousel__viewport[tabindex=0]     (scroll-snap-type: x mandatory)
│  └─ div.shad-carousel__track > div.shad-carousel__slide ×n
├─ button.shad-carousel__prev / __next
└─ div.shad-carousel__dots                     (dots generated by JS)
```
Modifiers: `.shad-carousel--halves` / `--thirds` (slides per view); `.shad-carousel--inset` (buttons inside edges).

## Methods / Events
`getValue()` → current index (0-based); `setValue(i)` scrolls to slide; `next()/prev()`; `refresh()` after slide swaps; `destroy()`. `shad:change {value: index}` after the snap settles (80 ms debounce).

## Keyboard
Viewport focusable: ←/→ page; native Tab reaches prev/next/dots.

## A11y
`aria-roledescription=carousel`; slides `role=group` + `aria-roledescription=slide` + "n of m" labels; buttons disabled at bounds via `data-disabled`; dots labelled.
