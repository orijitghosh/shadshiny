# label (Tier 1, CSS-only)

## Anatomy
`label.shad-label[for]`

## Data-attribute API
`data-disabled` – dimmed + not-allowed cursor.

## Methods / Events
None. R wrapper: `shad_label(text, for_id, disabled)`.

## A11y
Always pair with a control via `for`/`id` or nesting.
